# TCF Site Vault - releases

Public release channel for the **TCF Site Vault** WordPress plugin (encrypted website backups to a private GitHub repository).

This repository only hosts installable plugin packages. In WordPress, TCF Site Vault checks it for new versions (Settings > Updates, source "GitHub releases", repository `thelazy3d/tcf-site-vault`) and offers them on the normal Plugins / Updates screens.

* Download: see [Releases](../../releases) - `tcf-site-vault-X.Y.Z.zip` (with a `.sha256` checksum file).
* Install manually: Plugins > Add New > Upload Plugin.
* Your backups are never stored here; they go to your own private repository.
